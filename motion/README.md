## 参考与风格库

- [mg-styles-15](./mg-styles-15.md) — 15 种 MG 动态设计风格，每种一支 10 秒成片，附风格说明、完整提示词和全部源码，AI 照提示词就能复刻同一风格。`MIT`
- [huashu-art-motion](./huashu-art-motion.md) — 艺术动画 Skill：数十种艺术史风格配方 + 解说语法，用代码让画动起来（可拆参考片、长卷穿越、口播片段）。`MIT`
- [reanimate](./reanimate.md) — 逆向任意动效：把参考站/录屏/gif 录下来拆成参数，用你项目的 CSS / Framer / GSAP / three.js 重写，再用同样方法录一遍逐帧比对，通常 2–5 轮收敛。`MIT`

## 动作词汇

- [motion-prompt](./motion-prompt.md) — 192 个「该怎么跟 AI 说」的动作名词（MG 动作、运镜、UI 组件、落地页效果、摄影风格），每个配动态示例、一行释义和提问范例，不用再靠形容词猜。`MIT`

## 工程库 Skill

- [gsap-skills](./gsap-skills.md) — GreenSock 官方：教 agent 正确写 GSAP（时间轴、ScrollTrigger、插件、React/Vue/Svelte、性能）。`MIT`

## 生成器

- [animate](./animate.md) — Claude Code skill：一个 `<canvas>` 程序化绘制 + 程序化配乐，逐帧确定性渲染成 MP4，做讲解片/历史/小故事；7 种内置风格，或照你的参考图新配一种。`MIT`
