# AI 创作开源项目索引

只收**开源**的、能帮 AI 做创作的项目：网页设计、动效、AIGC。领域 = 一级文件夹；子领域写在文件夹 `README.md` 的标题里，某一类攒到十几条再升成子文件夹。

## 收录标准

- 开源，能自己跑起来。
- 帮 AI（或人 + AI）完成某类创作：出代码、出界面、出动效、出图、出片、出声音。
- 不收闭源产品、商业 SaaS。

平台级能力（不是仓库，如浏览器原生 API）也收，但单独标记 `（平台能力，非仓库）`。

## 条目格式

```md
- [项目名](链接) — 一句话说清楚它帮 AI 做什么。`协议` ⭐star 数
```
