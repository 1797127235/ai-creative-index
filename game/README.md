## 资产

- [pixelfx](./pixelfx.md) — 244 个像素特效/动画，每个都是一小段代码，可网页实时播、改色镜像、导出精灵图进任何引擎；附 Claude Code skill，按像素美术师的方式（草稿→渲染→看→修）做新的。`MIT`
- [scenario-labs/skills](../studio/scenario-skills.md) — 经 Scenario MCP：精灵/图标/瓦片/像素风、动画表、横版套件、贴图与天空盒、引擎向 3D 导出等（同包还覆盖通用图像/视频/音频/3D；主条目在 studio/）。`MIT`

## 工作流

- [Claude-Code-Game-Studios](./Claude-Code-Game-Studios.md) — 把一次 Claude Code 会话变成游戏工作室：49 个按职级分工的 agent + 74 个流程 skill（设计→开发→QA→发布），从脑暴到上线有人盯质量门。`MIT`

## Three.js 游戏 Skill
